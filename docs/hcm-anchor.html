Heightened Cash Monitoring Anchor

Purpose. The federal Heightened Cash Monitoring (HCM) list places institutions under enhanced cash-disbursement oversight, often years before any closure. HCM placement is a separate distress signal from closure, with a different base rate and a different time profile. This track explored using HCM as a separate anchor for the higher-ed extension.

Outcome

Source-blocked in this run. Federal endpoints hosting the HCM list were not reachable from the build environment used for this work. The Urban Institute Education Data Portal — which provides the federal Financial Responsibility composite-score mirror — does not republish HCM. No alternative public mirror with HCM identifier-level data was located. As a result, no HCM evidence is incorporated into the locked claim.

What this track does NOT claim

  • It does not claim HCM placement is or is not predicted by the higher-ed A/G geometry.
  • It does not claim HCM data was incorporated into any validated label.
  • It does not infer historical HCM dates from indirect sources or unofficial scrapes; the project rule against fabricated labels stays in force.

Future work

HCM remains a clean candidate for a future iteration. A future user with direct browser access to the federal HCM XLSX could:

  1. Download the file from the federal source with documented provenance.
  2. Resolve OPEID to UNITID using the project’s existing IPEDS HD crosswalk.
  3. Define an HCM-placement label at panel year T per institution.
  4. Run an HCM-as-target validation parallel to the closure validation, restricted to the same FASB × Sector 2 lane initially.

That work would either confirm a separate HCM-relevant signal in the same geometry, or surface a different geometry winner for HCM and update the higher-ed regime taxonomy accordingly.

Reproducibility

The locked higher-ed result is reproducible from documented Python scripts and public IPEDS data. The full reproducibility runbook, the artifact index marking files as CURRENT / HISTORICAL / SUPERSEDED, and the curated minimum-evidence packet are part of the project repository. They are not republished here as standalone files because they describe internal paths; the same information is summarised in the document pages above.

The project records SHA-256 fingerprints for every raw IPEDS zip (per the per-phase fetch logs) and an MD5 lock baseline for the locked-evidence documents and CSV outputs. A reviewer who needs to verify the lock can compute the same fingerprints from the public IPEDS sources.

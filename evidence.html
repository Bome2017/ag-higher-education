Evidence

This page indexes the reader-facing summaries of the documents behind the locked higher-ed result. The summaries are written for a non-internal audience; the full markdown source documents stay in the project repository for reviewers who need the raw record.

No institution-level scores, no institution-level rankings, and no raw IPEDS data are linked from this page. The aggregated validation tables (cohort-level metrics, fold AUROCs, regime base rates) are summarised in each document’s page.

Core validation

Cluster Bootstrap

Institution-level (UNITID) bootstrap of the closure AUROC. Cluster-bootstrap 95 % CI compared with the original analytic Hanley-McNeil interval, plus paired-difference distribution against the strongest tested single-variable baseline.

Read the Cluster Bootstrap Note →

Temporal Folds

Four sliding train/test time-block folds. Joint-weak AUROC stays in [0.77, 0.86] across all four folds; honest record of the Fold-1 baseline tie.
